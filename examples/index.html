Leaflet.DistortableVideo

Warps an HTML5 video onto four arbitrary map corners using CSS 3D transforms, so footage can be registered to the ground it was filmed over. Every example below is live — pan and zoom the map.

GitHub npm Documentation

Leaflet 1

1.9.4

Most of these show footage that is not aligned to the map being registered onto the ground it covers — which is the reason the plugin exists. These use Leaflet 1's lowercase factories (L.map, L.latLng).

  • Corners object

    Footage stored 30° off north-up, placed on the ground it actually covers. Four named corners.

  • LatLngBounds

    North-up footage on two opposite corners. Axis-aligned, so it takes the scale-and-translate path.

  • Point array

    The same rotated footage and corners, given as a clockwise array.

  • Rotated map

    Rotated footage on a rotated map, bearing 0–360° via leaflet-rotate-map.

Leaflet 2

2.0.0-alpha.1 alpha

Leaflet 2 replaced the factories with constructors (new L.Map) and made the ES module the default entry point, so a script-tag page loads dist/leaflet-global.js. The plugin itself needs no version switch — the same build serves both.

  • Leaflet 2, all three inputs

    Side by side against stock L.VideoOverlay on the same clip, so you can see what the plugin is actually doing.

Leaflet 2 is still an alpha release. The plugin works with it today, but it overrides several of Leaflet's internal overlay methods, so treat 2.x support as provisional until Leaflet 2 stabilises.

These pages have no network dependencies — Leaflet and both clips are vendored, and a static Blue Marble image sits below the tile layer so the demos still work with no connection. Online the tiles cover it.

The footage is NASA GIBS VIIRS/SNPP true-colour imagery of the eastern Pacific, 8–15 October 2024 — public domain, and self-hosted rather than hotlinked. Both clips are regenerable with npm run demo:video; the settings that produced them are recorded alongside each file.

Every example places its footage on the exact ground it covers, so the coastlines continue out of the video and into the basemap. The corner-based demos use a clip stored 30° off north-up: the overlay rotates it back, which is work no plain image overlay can do.
